# Begriffsschrift

Begriffsschrift is a proof-assistant-oriented typeface based on Iosevka.

This project is currently an experimental fork of
[Iosevka](https://github.com/be5invis/Iosevka).

## Goals

- Add missing mathematical characters frequently used in proof assistants.
- Improve readability of mathematical operators, including large operators such as `∫`.
- Add proof-assistant-oriented ligatures such as `→*`.

## Status

Work in progress.
